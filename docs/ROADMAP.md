# 将来案（v0.1対象外）

- 初期値設定、ゲーム別プリセット（ライフ/スコア/ラウンド等）。
- BLE HIDの小型自撮りシャッター（AB Shutter系）をプレイヤー別に割り当て。設定時「Player N のボタンを操作してください」で識別し、番号を本体に記入。
- リモコン1台でまず2ボタン識別・スリープ復帰・再接続・電池消費を検証。その後に複数台同時接続可否を実証。1台で複数台接続の可否は確定できない。
- 接続断時の状態検出と再接続受付、プレイヤー割当保持。リモコンごとの接続仕様・HIDイベント差異に注意。
- Cardputer ADV / M5Stack親機、CYD表示子機、無線協調、状態同期、再接続。
- スマホへ状態送信し外部ディスプレイとして表示。UIレンダリングをスマホ側へ移す構想。
- 電池/USB給電対応の筐体とスタンド、将来の大画面対応。

これらのために今必要なのは **状態・コマンド・表示の分離**。無線プロトコルや汎用通信フレームワークを初版に作らない。
